# Погода на сутки для M5Stack PaperS3

Прошивка для M5Stack PaperS3, которая показывает на e-ink экране текущую погоду и подробный почасовой прогноз на 24 часа. Экран расположен альбомно, 960×540.

## Как работает

1. Нажатие кнопки **Power** включает устройство.
2. Устройство подключается к Wi-Fi.
3. Определяет местоположение по IP: сначала через ip-api.com, при неудаче через ipwho.is.
4. Загружает прогноз с [Open-Meteo](https://open-meteo.com), ключ API не нужен.
5. Рисует экран и **выключает питание**. На e-ink изображение остаётся и без питания.

При питании от USB полностью выключиться нельзя, поэтому устройство уходит в глубокий сон.

Если обновить данные не удалось (нет сети или сервер не ответил), на экране остаются последние успешно загруженные данные. Внизу появляется плашка с причиной ошибки. Данные хранятся в NVS.

## Что на экране

- **Сверху, текущая погода:** иконка, температура, описание, «ощущается как», ветер (м/с и направление), влажность, давление (мм рт. ст.), восход и закат, город, заряд батареи.
- **Ниже, прогноз на 24 часа.** Начинается с последнего часа, кратного 3: в 16:40 первая точка будет 15:00.
  - Заголовок: сегодняшняя дата, максимальная и минимальная температура за день, сумма и вероятность осадков.
  - Каждые 3 часа: время, иконка погоды, температура. Полночь подписана днём недели и отмечена пунктиром.
  - График температуры по часам.
  - Столбики осадков по часам. Шкала не мельче 1 мм/ч, чтобы морось не выглядела ливнем.
  - Под столбиками для каждого 3-часового интервала: сумма осадков в мм и максимальная вероятность. Вероятность от 50% выделена чёрным.
- **Внизу:** время последнего обновления.

## Настройки

Все настройки находятся в начале файла `Paper_s3_weather.ino`.

| Параметр | Назначение |
|---|---|
| `WIFI_SSID`, `WIFI_PASS` | Сеть Wi-Fi, только 2.4 ГГц |
| `FALLBACK_GW` | Адрес основного роутера (по умолчанию `192.168.178.1`), см. раздел «Особенности сети» |
| `FIXED_LAT`, `FIXED_LON`, `FIXED_CITY` | Фиксированное местоположение. Если оставить `NAN`, оно определяется по IP |

## Сборка и прошивка

Что нужно:
- arduino-cli;
- ядро `m5stack:esp32` (проверено на 3.2.2);
- библиотеки **M5Unified**, **M5GFX** и **ArduinoJson** 7.x.

Прошивка весит около 1.7 МБ. В проекте есть свой `partitions.csv` с разделом приложения на 6 МБ, чтобы был запас. Ядро подхватывает его автоматически, но при сборке нужно поднять лимит размера:

```bash
arduino-cli compile -b m5stack:esp32:m5stack_papers3 \
  --build-property upload.maximum_size=6291456 \
  --output-dir build .
```

Первая прошивка, вместе с таблицей разделов:

```bash
esptool --chip esp32s3 -p /dev/ttyACM0 -b 460800 write_flash -z 0x0 build/Paper_s3_weather.ino.merged.bin
```

Следующие обновления, только приложение. Так быстрее, и кэш погоды сохраняется:

```bash
esptool --chip esp32s3 -p /dev/ttyACM0 -b 460800 write_flash -z 0x10000 build/Paper_s3_weather.ino.bin
```

Используйте esptool из ядра Arduino, например `~/.arduino15/packages/esp32/tools/esptool_py/5.0.0/esptool`. В системном пакете esptool нет stub-загрузчика для ESP32-S3.

### Если порт не появляется или прошивка не запускается

Устройство большую часть времени выключено, поэтому порт `/dev/ttyACM0` пропадает. Нажмите **Power**, и прошивайте, пока устройство работает: на это есть примерно 5–10 секунд.

Если прошить всё равно не получается (например, ошибка `Protocol error`), переведите устройство в режим загрузки:
1. Нажмите **Power** до тех пор пока светодиод на обратной стороне не замигает красным.
2. Отпустите **Power**.

### Лог и снимок экрана

Прошивка пишет диагностику в USB-Serial на скорости 115200. После старта она ждёт 1.5 секунды, чтобы вы успели открыть монитор порта.

Если монитор порта открыт, после отрисовки прошивка отправляет содержимое экрана: строку `IMG_BEGIN 960 540`, затем 960×540 байт яркости (8 бит на пиксель), затем `IMG_END`. Так раскладку можно проверить без фото экрана.

## Шрифты

Сглаженные шрифты с кириллицей в формате VLW лежат в `fonts.h`. Их генерирует скрипт `tools/make_fonts.py` из DejaVu Sans; нужен Python с библиотекой Pillow. Чтобы поменять размеры или набор символов, отредактируйте список `FONTS` в скрипте и выполните:

```bash
python3 tools/make_fonts.py
```

## Особенности сети

Эти особенности выявлены при отладке.

- **Смешанный режим WPA/WPA2.** Точка доступа Akinava24 работает в режиме WPA1+WPA2. Ядро ESP32 3.x по умолчанию требует WPA2 и отклоняет такое подключение (статус 4, `CONNECT_FAILED`). В прошивке минимальный уровень защиты понижен: `WiFi.setMinSecurity(WIFI_AUTH_WPA_PSK)`.
- **Неработающие шлюз и DNS от DHCP.** Точка доступа 192.168.178.40 раздаёт по DHCP себя как шлюз и DNS, но DNS-запросы не обслуживает. Если имя не разрешается, прошивка оставляет выданный IP и ставит шлюз `FALLBACK_GW` и DNS 1.1.1.1 / 8.8.8.8. Правильнее отключить DHCP на точке доступа, то есть перевести её в режим моста. Тогда этот обход не понадобится.

### Диагностика Wi-Fi на экране

Если подключиться не удалось, устройство сканирует эфир и показывает одно из двух сообщений:
- «сеть … не найдена». Сети нет в эфире, или она работает только на 5 ГГц.
- «сеть найдена: сигнал, канал, статус». Сеть видна, но подключение отклонено. Проверьте пароль и режим защиты на роутере.

## Файлы

- `Paper_s3_weather.ino` — исходный код прошивки.
- `fonts.h` — сгенерированные шрифты.
- `tools/make_fonts.py` — генератор шрифтов.
- `partitions.csv` — таблица разделов: NVS, приложение 6 МБ, SPIFFS, coredump.
- `build/` — результаты сборки.
